# Focus (Desktop) — User Guide

Welcome to Focus! This software is for boosting your productivity and effeciency by organising your chosen files, links, quick notes and pointing arrows on the center pane.  
You can store, view and read most of all existing file types (more than 70 in total) and web links without any external software or web browsers. You can also type plain text anywhere on the main area as a quick note (mouse left double click) and draw arrows (drag anywhere holding left mouse button pressed).

## What Focus does
- Keep your key files, links, and notes in one place using customizable **Spaces**.
- View 70+ file types directly on the canvas or in the preview sidebar.
- Write quick notes with a double-click and sketch arrows to connect ideas.

## Quick start
1) Install and launch the app (download the latest release for your platform).  
2) Create or select a **Space**.  
3) Add stuff: drag files in, paste or type links, or double-click to add a quick note.  
4) Click any item to focus it—details and previews appear on the right sidebar.  
5) Drag items to rearrange the canvas to your liking.

## Working on the canvas
- **Quick notes**: Double-click empty space to type plain text anywhere.
- **Arrows**: Click and drag with the left mouse button held to draw pointing arrows.
- **Move/organize**: Drag tiles to reposition; resize where supported.
- **Open/preview**: Single-click to preview on the right; double-click a tile to open in its native app (when applicable).

## Supported content (high level)
- Documents (Word, Excel, PDF, HTML), ebooks (EPUB/FB2/MOBI/etc.), images, audio, YouTube/Vimeo, and common text/code files—over 70 formats total.
- Links render with titles/thumbnails where available; text files show a snippet on the tile.

## Google integration (optional)
- Use the **Connect Google** flow to add Gmail or Drive entry points as objects.
- You can disconnect any time from the same menu.

## Tips
- Use multiple **Spaces** to separate projects or contexts.
- Keep frequently used files/links near the center; park reference items around the edges.
- Pair quick notes with arrows to outline workflows or reading order.

## Need help?
- Check `README.md` for developer details and setup.
- If something looks off, restart the app and reopen the Space; report recurring issues with steps to reproduce.
